How-To

Import a Discord Server

  1. Open a Tavern server and click the Discord icon.
  2. Connect Discord in a second tab.
  3. Return and click I've Authorized.
  4. Select Discord server and import options.

Customize Sidebar Layout

  1. Drag channels/separators to reorder.
  2. Add separators from the channel action bar.
  3. Collapse sections as needed.
  4. Layout syncs for all members in the server.

Troubleshoot Discord Import

  1. If OAuth fails: verify redirect URI exact match.
  2. If guild unknown: ensure bot is in that guild.
  3. If unauthorized: reconnect OAuth and refresh.
